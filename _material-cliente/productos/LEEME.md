# Fotos de productos

Fotos propias de AUTIND, una o varias por producto. El nombre del archivo es el id que se pone en
`src/data/productos.json` → `fotos` (sin espacios ni tildes, por ejemplo `nb1-63-1.jpg`, `nb1-63-2.jpg`).

Después de agregarlas: `npm run productos` (pasa las fotos a AVIF/WebP en `public/img-productos/`).
Guía completa en `docs/PRODUCTOS.md`.
